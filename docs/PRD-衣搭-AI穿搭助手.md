# PRD: 衣搭 — AI 穿搭助手

## Overview

### Problem Statement

18-45 岁女性频繁面临「出门前纠结穿什么」的日常困扰，衣柜衣服不少却总觉得没衣服穿。现有 App 要么偏衣橱管理（Stylebook），要么偏社交分享（好搭），缺少一个轻量、快速、有 AI 辅助的搭配工具。同时，购买新衣服时缺乏决策参考，「这件该不该买」是高频痛点但尚无产品覆盖。

### Solution Summary

衣搭是一款面向 18-45 岁女性的 AI 穿搭助手。用户拍照上传衣物后，通过三层独立滑动（上衣/下装/鞋子）自由搭配，或使用 AI 根据天气、场合、风格一键推荐。同时提供「买前 AI 咨询」功能，辅助购买决策。

### Target Users

| 维度 | 描述 |
|------|------|
| 用户群体 | 18-45 岁女性，对穿搭有要求 |
| 核心痛点 | 每天纠结穿什么；买新衣时不确定是否适合自己 |
| 衣柜规模 | 20-50 件衣物，品类基本齐全 |
| 技术认知 | 熟练使用智能手机，对 AI 功能接受度高 |

## Scope

### In Scope（MVP）

- 拍照上传衣物（相册选取，自动抠图）
- 三层滑动搭配（上衣/下装/鞋子独立切换）
- AI 一键完整搭配（天气+场合+风格，仅从衣柜选）
- AI 补全搭配（固定单品 + AI 补全剩余）
- 天气适配 + 场合选择器（上课/约会/面试/通勤/运动）
- 买前 AI 咨询（V1.5）
- 收藏搭配
- 衣柜管理（分品类查看/编辑/删除）
- 衣柜统计

### Out of Scope

- 用户注册/登录系统（MVP 采用本地存储）
- 多设备同步
- 社交/分享功能
- 电商导购

## Solution Design

### 页面结构

底部导航（4 Tab）：

| 页面 | 核心功能 |
|:----|----------|
| 搭配（首页） | 天气、场合、三层滑动、AI 入口 |
| 衣柜 | 分品类展示、上传入口、编辑管理 |
| AI 助手 | 买前咨询 + AI 搭配入口 |
| 我的 | 风格偏好、收藏、统计、设置 |

### 核心交互

**三层滑动搭配：**
```
👚 上衣层 ← 左右滑动切换 →
👖 下装层 ← 左右滑动切换 →
👟 鞋子层 ← 左右滑动切换 →
```

**三种 AI 模式：**

| 模式 | 触发 | 逻辑 |
|:----:|------|------|
| A：一键搭配 | 点「AI 搭配」 | 天气→场合→风格→配色排序 |
| B：补全搭配 | 选中单品 + AI | 固定选中项，AI 补全其余 |
| C：买前咨询 | AI 助手页进入 | 上传衣物信息，AI 分析 |

### AI 质量保障四层机制

1. **Prompt 规则**：详细穿搭规则（配色、廓形、场合要求）
2. **用户画像**：风格偏好 + 行为学习
3. **规则引擎兜底**：拦截明显错误，触发黄金保底方案
4. **持续优化**：记录用户偏好，逐步提升推荐

## Technical Considerations

| 项目 | 方案 |
|------|------|
| 前端 | HTML + CSS + JavaScript（Web App） |
| AI 模型 | DeepSeek API（性价比高，国内可直连） |
| 图片处理 | @imgly/background-removal（浏览器端抠图） |
| 数据存储 | 本地 LocalStorage（MVP） |
| 天气 | 免费天气 API |
| 部署 | 静态页面托管 |

### 为什么选择 DeepSeek

DeepSeek 成本极低（¥0.5/百万 token），手机号即可注册，国内直连无需翻墙。充 ¥5 可跑数千次搭配，适合 Demo 阶段。正式上线后可考虑升级为 Claude 等模型。
